# 🍔 Hulk Lanches - Sistema de Atendimento

Sistema completo para lanchonetes com React, Node.js e PostgreSQL.

## 🚀 Tecnologias

- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Node.js + Express
- **Banco de Dados:** PostgreSQL
- **Comunicação:** WebSocket (Socket.io)

## 📦 Instalação

```bash
git clone https://github.com/applucasmt/hulklanches.git
cd hulklanches

# Backend
cd backend
npm install
npm run dev

# Frontend (outro terminal)
cd frontend
npm install
npm run dev
